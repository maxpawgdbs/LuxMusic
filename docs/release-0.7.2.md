# LuxMusic 0.7.2

## Интерфейс и обработка ошибок

- На пустом плеере доступны прямые действия «Добавить музыку» и «Скачать по ссылке».
- Действия из интерфейса и Activity Result API проходят через общий обработчик исключений; фоновые ошибки остаются в общей очереди уведомлений.
- Ошибки открытия браузера и внешних ссылок больше не подставляют адрес авторизации и одноразовый код в текст уведомления.
- Отмена coroutine не превращается в ошибку; после уведомления интерфейс продолжает принимать действия.

## Совместимость

Обновляйте приложение поверх установленной версии. `applicationId`, подпись APK, каталог `files/luxmusic` и схема библиотеки не изменены; миграции или очистки локальных данных в этой версии нет. Версия кода поднята выше 0.7.1.

## Проверки

JVM regression tests и Android instrumentation/UI tests запускаются в CI без Docker. Для обоих типов создаются JaCoCo-отчёты, а CI объединяет попадания по исходным строкам и публикует итог вместе с исходными отчётами.

В проверочном прогоне этой версии прошли 157 JVM- и 25 Android-тестов (один live-download тест условно пропущен). Совокупное line coverage составило 43,62%; запрошенный порог 90% не достигнут и не маскируется исключением непокрытых частей приложения.
