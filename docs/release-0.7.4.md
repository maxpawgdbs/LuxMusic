# LuxMusic 0.7.4

## Интерфейс

- На главную вернулась вертикальная композиция плеера: обложка над названием и кнопками управления. Обложка немного уменьшена, чтобы занимать меньше места.
- Убрали дополнительный верхний отступ над карточкой плеера. На небольших экранах главная прокручивается, так что кнопки управления остаются доступными.
- Нижняя панель навигации стала в 1,5 раза выше. Подписи вкладок по-прежнему скрыты, но доступны через описания для экранных дикторов.
- Рекламный баннер на главную не возвращался. Очередь по-прежнему открывается рядом с названием трека.

## Совместимость

Устанавливайте APK поверх существующего приложения, не удаляя его и не очищая данные. `applicationId`, ключ подписи, путь `files/luxmusic` и формат библиотеки не изменены: скачанная музыка и плейлисты сохраняются.

## Проверки

Локально без Docker прошли 158 JVM-тестов и 27 Android-тестов на эмуляторе. Android Lint и сборка подписанного универсального APK также прошли. Android-тесты запускались через `adb shell am instrument`, поскольку локальный Gradle UTP не смог загрузить свои вспомогательные библиотеки из Maven Central; это не повлияло на сами тесты. Перед публикацией релиза GitHub Actions повторно запускает проверки и прикрепляет APK. Telegram-бот публикует отдельный пост со ссылкой на готовый релиз и сразу завершает работу.
