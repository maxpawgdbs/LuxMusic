# LuxMusic 0.7

- YouTube: yt-dlp с QuickJS, извлечение аудио FFmpeg, поддержка потока с видео и звуком. Удалены вход YouTube и импорт cookies.
- TikTok: обычная загрузка, обновление экстрактора после ошибки и резервный источник TikWM. Для фотопубликаций сохраняется доступная звуковая дорожка.
- Ошибки операций, выбора файлов и воспроизведения показываются уведомлениями. Сообщения ожидают появления экрана, отмена не запускает повторную загрузку.
- Сохраняется резервная копия каталога. Восстанавливается старый AtomicFile `.bak`; повреждённый каталог защищён от перезаписи, доступные записи сохраняют прежние пути и идентификаторы.
- Обложки декодируются в фоне с ограниченным разрешением. Загрузка Яндекс-дискографии сохраняет треки небольшими партиями и ограничивает кэш обложек.
- Исправлено отображение полной очереди плеера. Обложка хранится в медиасессии только для текущего трека, чтобы большие очереди не заполняли память изображениями.
- Восстановление очереди не запускает воспроизведение при получении устаревшего служебного Intent. Обновление экстрактора ограничено по времени и не блокирует резервную загрузку бесконечно.
- Стандартный запуск JVM-тестов автоматически включает новые тесты. Добавлены Android-проверки интерфейса и совместимости библиотеки.

Устанавливайте APK поверх старой версии. Удаление приложения или очистка его данных удаляет локальную библиотеку; обновление APK этого не делает. Подпись `luxmusic-dev`, пакет `com.luxmusic.android` и каталог `files/luxmusic` сохранены. `versionCode` увеличен с ветки 6 002 xxx до 7 000 xxx, включая совместимость с ошибочно названным релизом 6.0.1.

Доступность конкретных публичных ссылок зависит от площадок и сети. Приватные, удалённые и ограниченные публикации могут вернуть сообщение об ошибке.
