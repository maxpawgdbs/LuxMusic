# LuxMusic 0.7.3

## Интерфейс

- На главной больше нет рекламного баннера и прокрутки. Обложка и сведения о треке стоят рядом; полоса прогресса и все кнопки воспроизведения видны сразу на компактном экране.
- Очередь открывается кнопкой рядом с названием текущей песни.
- На основных вкладках убрана верхняя панель с повтором названия раздела. Нижнее меню стало ниже и показывает только значки; у кнопок сохранены описания для доступности.
- Настройки открываются только из раздела «Загрузка». Назад из настроек возвращает в загрузку.
- В библиотеке статистика коллекции собрана в короткую строку. Баннер канала перенесён наверх вкладок «Библиотека», «Артисты» и «Плейлисты».

## Совместимость

Обновляйте APK поверх установленного приложения. `applicationId`, подпись, каталог `files/luxmusic` и формат библиотеки не изменены; скачанная музыка и плейлисты сохраняются.

## Проверки

Локально без Docker прошли 157 JVM-тестов и 26 Android-тестов; один условный тест живой загрузки пропущен. Android Lint и сборка подписанного выпускного APK также прошли. UI-тесты проверяют компактную навигацию, положение баннера, доступность настроек и видимость управления плеером на небольшом экране.
